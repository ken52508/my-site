Speckle Image Classification Across Voltage Conditions

Trained neural network classifiers on speckle images from a voltage-tunable PDLC optical scattering system, then tested how well a model trained at one voltage classifies data captured at another.

An image is shown on a spatial light modulator, scattered through a voltage-tunable PDLC cell, and captured by a CCD camera as a speckle pattern. Voltage controls how much the image scatters, from near-clear at 0V to heavily diffused at 3V. A neural network takes the speckle image and predicts the original class.

What I Built

Optical Data Pipeline

Set up the SLM, PDLC, and CCD chain and collected speckle images at 4 voltage levels.

Model Comparison

Trained an MLP baseline, a CNN baseline, and a multi-task model that classifies and reconstructs the image at once, on the same data.

Multi-condition Evaluation

Tested every model on all 4 voltage levels, not just the one it trained on. 4×4 matrix, 16 train/test pairs per model.

Reproducibility

Repeated every training run with 3 random seeds (42, 123, 999) to check results against training noise.

Data Quality Analysis

Checked file paths, voltage labels, and checkpoint loading before trusting any accuracy number.

Most Interesting Finding

Training at 1V, testing at 0V: 63.8% average accuracy

Dashed line marks where most other train/test voltage pairs land.

  • Seed 42: 66.2% · Seed 123: 65.7% · Seed 999: 59.5%
  • Most other cross-voltage combinations: below 32%
  • Reproduced across three independent training runs, not a training artifact

How I Investigated It

1

Verified implementation

Checked file paths, voltage labels, and checkpoint loading. Ruled out a data pipeline bug before looking anywhere else.

2

Tested reproducibility

Reran training with three different random seeds. The result held in all three: same direction, similar magnitude.

3

Checked possible explanations

Reviewed related work on PDLC scattering behavior at low voltage. Found partial support for low-voltage speckle patterns being more similar to each other, and added a direct measurement to the next-steps list.

What This Project Demonstrates

System Thinking

Connected hardware (SLM, PDLC, CCD), data pipeline, and model design into one evaluation, and tracked how a change in one layer affects the others.

Experimental Design

Built a 4×4 cross-voltage test matrix instead of a single train/test split, so results would hold up under more than one condition.

Root-Cause Investigation

Traced an unexpected result through data labels, checkpoints, and prior literature before accepting it as real.

Data-Driven Decision Making

Used reproducibility across three seeds as the bar for whether a result was worth reporting.

Technical Communication

Documented an open-ended result clearly: what's confirmed, what isn't, and what to check next.

Cross-domain Engineering

Worked across optics hardware, data pipelines, and deep learning in one project, translating between the physical setup and the model layer.

Next Steps

  • Run a feature-space analysis on the multi-task model to see what it learned across voltages.
  • Test whether the same pattern shows up in other low-voltage train/test pairs, not just 1V→0V.
  • Measure speckle contrast directly instead of inferring it from accuracy alone.

圖片透過空間光調變器（SLM）顯示，經過電壓可調的 PDLC 元件散射後，由 CCD 相機拍下散斑影像。電壓控制散射程度，從 0V 接近清晰到 3V 高度模糊。神經網路直接吃散斑影像，輸出預測的類別。

做了什麼

光學資料蒐集流程

架設 SLM、PDLC、CCD 的量測鏈路，在 4 個電壓下蒐集散斑影像。

模型比較

用同一批資料訓練三種架構：MLP 基準模型、CNN 基準模型，以及同時做分類與重建的多任務模型。

多條件評估

每個模型都在全部 4 個電壓下測試，不只測訓練時用的那個電壓。4×4 矩陣，每個模型共 16 組訓練/測試組合。

可重現性

每組設定都用 3 組隨機種子（42、123、999）重複訓練，用來排除訓練雜訊。

資料品質檢查

採信任何準確率數字之前，先確認檔案路徑、電壓標籤、checkpoint 載入都對得上。

最有意思的發現

訓練於 1V、測試於 0V：平均準確率 63.8%

虛線標出其他大多數訓練/測試電壓組合落在的範圍。

  • Seed 42：66.2% · Seed 123：65.7% · Seed 999：59.5%
  • 其他大多數跨電壓組合：準確率低於 32%
  • 三次獨立訓練都重現同樣的結果，不是單次訓練的偶然

怎麼排查

1

確認實作沒問題

檢查檔案路徑、電壓標籤、checkpoint 載入，先排除資料流程上的錯誤，再往別的方向查。

2

測試可重現性

換三組不同的隨機種子重新訓練，三次結果方向一致、數值也相近。

3

檢查可能的原因

查閱 PDLC 散射相關文獻，找到低電壓範圍散斑統計特性較接近的間接證據，並把直接量測列進下一步要做的事。

這個專案展現的能力

系統思維

把硬體（SLM、PDLC、CCD）、資料流程、模型設計串成一個完整的評估流程，清楚每一層的改動會如何影響其他層。

實驗設計

設計 4×4 跨電壓測試矩陣，而不是單一組訓練/測試切分，讓結果禁得起不只一種條件的檢驗。

根因調查

把一個非預期的結果，從資料標籤、checkpoint 到相關文獻一路查下去，確認之後才採信。

資料驅動的判斷

用三組種子都能重現，當作一個結果值不值得寫進報告的門檻。

技術溝通

把一個還沒有確定機制的結果寫清楚，分開哪些已經確認、哪些還是開放問題。

跨領域工程能力

同時處理光學硬體、資料流程、深度學習模型，在硬體與模型之間來回轉換。

下一步

  • 對多任務模型做特徵空間分析，看它在不同電壓下實際學到了什麼。
  • 驗證同樣的規律是否出現在其他低電壓的訓練/測試組合，不只 1V→0V。
  • 直接量測散斑對比度，而不是只從準確率推論。
